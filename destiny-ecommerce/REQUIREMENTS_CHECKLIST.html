6 Authentication

Secrets used to sign and verify login tokens. Must be generated securely — never share these publicly.

JWT_SECRET (Access Token Secret)Required
How to Generate
Run in terminal: node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
Expected Format
Random hex string, minimum 64 characters
Example
a3f8b2c1d9e4f7a0b3c6d2e5f8a1b4c7d0e3f6a9b2c5d8e1f4a7b0c3d6e9f2a5
Why Needed
Signs login tokens — if compromised, all user sessions are at risk
Can Launch Without?
✗ No — nobody can log in without this
JWT_REFRESH_SECRET (Refresh Token Secret)Required
How to Generate
Same command as above — generate a different value from JWT_SECRET
Why Different
If one secret leaks, the other still protects sessions. Never use the same secret twice.
Can Launch Without?
✗ No — refresh tokens will fail, users get logged out every 15 minutes
Session Timeout PreferencesRecommended
Current Settings
Access token: 15 minutes | Refresh token: 7 days
Question for Owner
Should customers stay logged in for 7 days, 30 days, or until they explicitly log out?
Can Launch Without?
✓ Yes — current 7-day refresh is standard
