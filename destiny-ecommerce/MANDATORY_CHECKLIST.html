SendGrid Setup

  • Register at sendgrid.com
  • Settings → API Keys → Create Full Access key
  • SMTP_HOST = smtp.sendgrid.net
  • SMTP_PORT = 587
  • SMTP_USER = apikey (literally the word "apikey")
  • SMTP_PASS = SG.your-api-key-here
  • Verify sender domain via DNS TXT/CNAME records
  • Sender Authentication → Domain Authentication

Gmail SMTP Setup

  • Enable 2-Factor Authentication on Google account
  • Google Account → Security → App Passwords
  • Select App: Mail, Device: Other → Generate
  • SMTP_HOST = smtp.gmail.com
  • SMTP_PORT = 587
  • SMTP_USER = your@gmail.com
  • SMTP_PASS = xxxx xxxx xxxx xxxx (app password)
  • ⚠️ Max 500 emails/day limit

Required DNS Records (SendGrid Domain Authentication)

  • SendGrid provides 3 CNAME records to add to your domain's DNS
  • These authenticate your domain and prevent emails going to spam
  • Takes 24-48 hours to propagate
  • Check status in SendGrid → Settings → Sender Authentication
ENVIRONMENT VARIABLES SMTP_HOST=smtp.sendgrid.net SMTP_PORT=587 SMTP_USER=apikey SMTP_PASS=SG.your-key SMTP_FROM_EMAIL=hello@yourdomain.com SMTP_FROM_NAME=Destiny E-Commerce
  • Create SendGrid account and API key
    sendgrid.com → Settings → API Keys → Create Key (Full Access) → copy
  • Set all SMTP environment variables
    Add SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, SMTP_FROM_EMAIL, SMTP_FROM_NAME
  • Add DNS records for domain authentication
    SendGrid → Sender Authentication → add provided CNAME records to your DNS. Prevents spam folder.
  • Test email sending
    Place a test order → verify order confirmation email arrives. Check spam folder first time.

🗺️ Exact Steps to Launch (In Order)
  • Step 1: Create Neon account → get DATABASE_URL
    neon.tech → New Project → copy connection string
  • Step 2: Generate JWT secrets
    openssl rand -base64 64 (run twice, use different values)
  • Step 3: Create apps/api/.env from apps/api/.env.example
    Fill in DATABASE_URL, JWT_SECRET, JWT_REFRESH_SECRET, PORT=5000 minimum
  • Step 4: Run database migrations
    cd destiny-ecommerce/apps/api && npx prisma migrate dev --name init && npx prisma generate
  • Step 5: Start API locally and test
    npm run dev → visit http://localhost:5000/api/v1/health → should return {"status":"ok"}
  • Step 6: Start frontend locally and test
    cd apps/web && echo "NEXT_PUBLIC_API_URL=http://localhost:5000/api/v1" > .env.local && npm run dev
  • Step 7: Register your account and set SUPER_ADMIN role
    Register at localhost:3000/auth/register → connect to DB → UPDATE users SET role='SUPER_ADMIN' WHERE email='your@email.com';
  • Step 8: Add categories, brands, and products
    Admin panel at localhost:3000/admin/dashboard → navigate to each section
  • Step 9: Create Cloudinary account and add credentials
    cloudinary.com → Dashboard → copy Cloud Name, API Key, Secret → add to .env
  • Step 10: Create SendGrid account and add SMTP credentials
    sendgrid.com → API Key → add SMTP vars to .env → test email works
  • Step 11: Deploy API to Railway
    railway.app → New Project → GitHub → root=apps/api → add all env vars → deploy
  • Step 12: Deploy frontend to Vercel
    vercel.com → New Project → GitHub → root=apps/web → NEXT_PUBLIC_API_URL=https://your-api.railway.app/api/v1 → deploy
  • Step 13: Register domain and configure DNS
    namecheap.com → buy domain → add CNAME records pointing to Vercel and Railway URLs
  • Step 14: Set CORS_ORIGIN and redeploy
    CORS_ORIGIN=https://yourdomain.com → update in Railway → redeploy API
  • Step 15: Run full end-to-end test on production URL
    Browse → add to cart → checkout → pay via MTN → submit transaction ID → admin approve → confirm email received
